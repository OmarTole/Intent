# Intent — ежедневник

Сайт и PWA для задач, привычек и календаря.

Бета до 100 пользователей: [видение и текущее состояние](docs/VISION.md),
[рынок и план проверки пользователей](docs/MARKET_AND_BETA.md),
[изменения и результаты проверок](docs/BETA_CHANGELOG.md).

- Таблица месяца с тремя цветами и ручной оценкой выполнения.
- Настраиваемые группы и порядок направлений.
- Список задач дня, карточки, комментарии и история.
- Повторяющиеся события и push-напоминания.
- Регистрация, личные аккаунты и админка со статистикой.
- Офлайн-сохранение и синхронизация при подключении.

Стек: React, TypeScript, Vite, FastAPI, SQLAlchemy, PostgreSQL, Caddy.

## Размещение

[Инструкция: GitHub + сервер, HTTPS и уведомления](docs/HOSTING.md).

GitHub хранит исходники. Сайт требует отдельного сервера — GitHub Pages не запускает Python API и фоновую доставку уведомлений. Docker Compose по умолчанию запускает три сервиса: web, api и db. Ollama оставлен в необязательном профиле `ai`.

## Локальная разработка

Создайте Python 3.12 venv, установите `server/requirements-dev.txt`.
Из папки `server` запустите `uvicorn app.main:app --host 127.0.0.1 --port 18080`, задав `COOKIE_SECURE=false` только для локального HTTP.
В папке `web` выполните `npm ci` и `npm run dev`. Откройте `http://127.0.0.1:15174` и зарегистрируйтесь.

Проверки: `pytest` в `server`, `npm test` и `npm run build` в `web`.

## Личные данные

В репозитории нет паролей, VAPID-ключей, личной базы и резервных копий. Настройки создаются на сервере в `.env`. Новое размещение начинает работу с пустой базой; перенос существующих данных выполняется отдельно.
