## Где мы сейчас

- **Идея уточнена 20.10.2026.** Центр продукта — ИИ-ассистент в формате чата: понимает приказы и утверждения и сам создаёт задачи и напоминания. Дальше идут запросы знакомым с подтверждением и историей, после беты — открытый рынок намерений. Код пока устроен по-старому: главный экран — таблица прогресса, ИИ только предлагает черновики.
- **Что уже работает:**
  - ежедневник: таблица прогресса, «Мой день», календарь, повторения, комментарии и история;
  - push-напоминания и офлайн-режим с синхронизацией;
  - вкладка «Помощник»: фраза → черновик → подтверждение;
  - «Люди»: приглашения на разовое событие со временем, с принятием, отклонением и отменой;
  - вход по телефону, админка.
- **ИИ подключён к Groq (20.10.2026).**
  - Если задан `GROQ_API_KEY`, помощник использует облачную `openai/gpt-oss-120b`, иначе локальную Ollama. Локальный ключ лежит в `.local/groq.env`.
  - На 15 типовых фразах: Groq — 15/15 при среднем ответе 0,8 с, локальная Qwen3 4B — 14/15 при среднем 3 с.
  - Тест покрывает только черновики одной записи, а не диалог и не изменение и удаление задач.
  - Ограничение бесплатного Groq: ~4 сложных запроса в минуту и ~1000 в день на всё приложение.
- Проверки зелёные: 44 серверных теста, 25 веб-тестов, production-сборка.
- **Облако.** На Render работает коммит `3f33976` от 20.10.2026. Обновление понадобилось запускать вручную (Manual Deploy), поэтому, вероятно, выключен Auto-Deploy. План — Free, сервер засыпает.

## Технический долг и риски

- **Нет миграций БД.** Перед первым изменением схемы существующих таблиц (а запросы знакомым и чат его потребуют) подключить Alembic.
- **Телефон не подтверждается.** Можно зарегистрировать чужой номер и получать адресованные его владельцу запросы. Для запросов знакомым и тем более для открытого рынка нужно подтверждение по SMS.
- **Нет самостоятельного сброса пароля.** Пароль сбрасывает только админ.
- **Сессия живёт 10 лет.** Нет списка устройств.
- **Нет CI.** Тесты на GitHub не запускаются автоматически.
- **Рабочая папка — не git.** Ручная синхронизация с `.local/deploy-repo` рискованна. Стоит сделать git-репозиторием сам корень проекта.
- **Журнал `events` никто не читает,** `user_memories` нельзя редактировать. Память может пригодиться ИИ-чату.
- **Весь ежедневник отправляется целиком** при каждом сохранении (до 4 МБ). Для чата и запросов между людьми может понадобиться хранить задачи отдельными записями.
